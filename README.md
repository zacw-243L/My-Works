# My Works
A collection of my python scripts

A collection of pure, no-stakes Python experiments I built just because I could, whenever curiosity struck.
From brute-forcing "Hello World" in absurd ways and simulating the infinite monkey theorem with Shakespeare's full text, to messing around with fractal generators, bogosort, and polymorphic code tricks — it's all hobby coding at its most unserious. No deadlines, no grades, no clients; just me, a script, and the fun of seeing what happens when I push logic to silly extremes
